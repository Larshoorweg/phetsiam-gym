# Phetsiam Muay Thai Gym: website draft

Single-page website draft for Phetsiam Muay Thai Gym, Bangkok. Mobile first, with an English / Thai language switch and a clickable booking demo (front end only: nothing is sent, stored or paid).

## Files

- `index.html`: the page (styles, markup template and page logic)
- `runtime.js`: small renderer that fills the template and updates the page when you click
- `assets/`: photos, trainer posters, logo and favicons
- `vercel.json`: static hosting settings for Vercel

No build step. Open `index.html` through any static server, or deploy the folder as is.

## Status

First draft for review with the gym. Placeholders in square brackets (such as the WhatsApp number and opening hours) still need confirming.
